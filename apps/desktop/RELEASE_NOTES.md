## What's new

- When an update can't install itself automatically, Hindsight now shows a clear message with a "Download update" button that opens the release page — instead of a dead-end "update failed" error. This mainly affects the Linux `.deb`/`.rpm` packages, which need administrator permission to install. (Tip: the Linux **AppImage** build updates itself silently, with no password prompt — prefer it if you want hands-off updates.)
